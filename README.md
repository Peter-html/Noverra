# Nexus Mobile · Expo + React Native + TypeScript

## Included
- **Cinematic Nexus Hero Opening Animation**:
  - Cosmic obsidian void background (`#05070B`)
  - Multi-hued ambient aurora glows (electric cyan `#00F0FF`, hot magenta `#E01595`, and deep blue `#185BFF`)
  - Kinetic spring reveal and rotation of the iridescent faceted origami "N" emblem
  - Diagonal specular sheen sweep across the emblem facets
  - Expanding shockwave energy ring
  - Smooth tracking slide-in of the white "Nexus" typography
  - Holographic charging laser progress beam & dynamic status indicators
  - Shared-element **Hero Transition**: smoothly morphs from centered splash into the header brand anchor
  - Interactive skip & replay: tap the header brand logo or `⚡ Replay Intro` pill at any time to re-trigger the animation
- Modern sign-in and account picker screen
- Three allowed demo accounts: `anto@gmail.com`, `rufin@gmail.com`, `victer@gmail.com`
- Dashboard with 6 operational modules and sample records
- Type-checked with TypeScript and optimized for 60/120fps hardware acceleration

## How to Run on Your Phone
1. Open terminal in this folder:
   ```bash
   npx expo start
   ```
2. Scan the generated QR code using the **Expo Go** app on your iPhone or Android phone.
3. The app opens directly with the cinematic **Nexus Hero Opening Animation** on your phone screen!
4. Tap the screen anytime to quick-enter, or tap **⚡ Replay Intro** in the top navigation bar to watch it again.

`npm run typecheck` verifies TypeScript compilation with zero errors.
